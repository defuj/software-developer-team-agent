Dev Loop

Build, preview, fix —
on repeat

Agents run your app, inspect the UI, fix issues, and loop until it’s perfect. No manual screenshots required.

The visual development loop

Instead of describing UI bugs and waiting for screenshots, the agent runs an autonomous cycle: start the dev server, open the browser, take screenshots, check console errors, inspect network requests, analyze findings, fix code, and repeat.

Powered by Chrome DevTools MCP for navigation and inspection, agent-browser for annotated screenshots and visual diff, and portless for stable .localhost URLs.

Install

One command, any way you want

Install per-project or globally — OpenCode auto-detects both. Node.js 18+ required.

terminal — global install
$ npx opencode-agent-kit init --global
→ OpenCode home: ~/.config/opencode/
→ Copying skills, prompts, commands...
✓ Dependencies installed
✓ agentmemory ready
✅ opencode-agent-kit v1.3.144 installed globally!

Install once. Use in every project. OpenCode auto-detects it at ~/.config/opencode/

opencode-agent-kit global status opencode-agent-kit global update opencode-agent-kit global path
terminal — per-project
$ npx opencode-agent-kit init
